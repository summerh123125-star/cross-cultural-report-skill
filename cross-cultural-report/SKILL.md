# Cross-Cultural Report

## Overview

This skill supports J-1 exchange teachers in producing compliant, high-quality cross-cultural activity reports. It supplies (1) four blank, print-ready English form templates that anyone can simply fill in, (2) the exact field and regulatory requirements, and (3) a repeatable workflow from topic to submitted PDF. Use it to generate a fresh form, fill one in from user-provided facts, write the Overview/Impact prose, or audit an existing report before submission.

## When to Use

- "Make me a blank Cross-Cultural Report form" / "I need the fill-in template"
- "Help me write my domestic / virtual report"
- "Write the lesson plan for my culture activity"
- "Check my report — will it be accepted?"
- "Give me the form to fill in with pictures and captions"

## Bundled Templates

Four blank English templates live in `assets/`, each in two formats: an HTML file (opens in any browser, type directly, print/save as PDF) and a DOCX file (opens in Word/WPS, type into the table cells, save as PDF). Both formats contain no pre-filled personal data — only empty fields, short field labels, and brief grey fill-in hints.

| Template | Files (HTML / DOCX) | Use for |
|---|---|---|
| 1. Cross-Cultural Report (cover sheet) | `assets/01_cross_cultural_report.html` / `.docx` | Teacher / Location / Sponsor / Grade / Subject / Activity Date / Topic / Lesson / Type of Exchange / Target Audience |
| 2. Lesson Plan | `assets/02_lesson_plan.html` / `.docx` | Lesson Focus/Goals, Materials Needed, Learning Objectives, Preparation / Action / Reflection, Assessment |
| 3. Domestic Cross-Cultural Activity Report | `assets/03_domestic_report.html` / `.docx` | In-person classroom/community culture sharing (Domestic/Local) |
| 4. Virtual Cross-Cultural Activity Report | `assets/04_virtual_report.html` / `.docx` | Online exchange with a partner school abroad |

To deliver a template, copy the matching HTML and/or DOCX file to a user-chosen output location and explain how to fill it: type into the empty/grey areas, then export to PDF. Keep templates blank unless the user supplies facts to fill in.

## Key Knowledge (memorize; apply to every report)

### Legal basis — 22 CFR §62.10

Each J-1 exchange teacher must complete, every academic year, at least one activity from EACH of two categories:

1. **Domestic/Local** — an activity for the classroom, school, district, or community giving an overview of the teacher's home country (history, traditions, heritage, culture, economy, education system, etc.).
2. **Virtual Exchange** — an activity involving U.S. student dialogue with a school/students in another country (preferably the teacher's home country), supplementing the in-person exchange.

### Required information in every report (5 mandatory items)

1. Teacher's full name
2. Program sponsor name
3. Date(s) of the activity
4. Location of the activity (specific school / room)
5. Audience for and participants in the activity

Plus: a general overview including the topic, and the estimated impact.

### Program specifics

- Sponsor name: ask the user; common programs include Global Ambassador Programs (GAP).
- Submit through the portal or form specified by the user's program.
- Upload the lesson plan or detailed description together with evidence and pictures in ONE PDF.
- Two reports per year (one of each type); more may be required for an extension.
- Check the program deadline (often December 1) — recommend submitting early.
- Delete the suggestions/reference section from the template before submitting; add pictures WITH descriptions.

### User context

Do not assume any teacher name, school, room number, grade level, partner school, or partner teacher. Ask the user for these facts whenever a filled report is requested, and use placeholders until they are supplied.

## Workflow

1. **Identify deliverable** — blank form vs. filled report vs. lesson plan vs. compliance check.
2. **If blank form**: copy the matching template from `assets/` to the output folder; leave every field empty.
3. **If filled report**: collect the 5 mandatory items + topic + impact evidence, then write in the report's voice (formal, English). Mark unknowns with 【To fill】 rather than inventing names, dates, or numbers.
4. **Impact must be quantified** — include participant count, correctness/participation rates, work samples, student quotes, and impact on the teacher. Avoid vague claims.
5. **Always append a pre-submission checklist** covering the 5 mandatory items + overview + impact + lesson plan + captioned photos + one of each type.
6. **Audit mode**: compare the draft field by field against `references/requirements.md`; list missing items and give a concrete fix for each.

## Style Constraints

- Keep templates fully English; do not add Chinese to the forms.
- Keep forms minimal and visually clean — empty cells, thin borders, small grey hints, generous writing space.
- Never fabricate personal data, dates, or figures. Use placeholders like [Full Name], [MM/DD/YYYY].
- Target an intermediate English reader; plain, direct sentences.
